# Contributing

Thank you for your interest in contributing!

## How to help

### 🐛 Report a bug
Open an **Issue** with:
- What you were trying to do
- The command you ran
- The error message or unexpected output
- Your OS and Python/Node version

### ✨ Suggest a feature
Open an **Issue** tagged `enhancement` describing:
- What problem it solves
- Roughly how it should work

### 📝 Submit a fix or improvement
1. Fork this repo
2. Create a branch (`git checkout -b fix/your-fix`)
3. Commit your changes
4. Push and open a Pull Request

### 🔒 Security disclosures
If you find a security vulnerability, please **do not** open a public Issue. Instead, open an Issue with `[SECURITY]` in the title — it will be reviewed privately.

## Code style

- Follow existing conventions in the codebase
- Keep commits atomic and descriptive
- Update the README if user-facing behavior changes
